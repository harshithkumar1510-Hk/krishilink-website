# KrishiLink Website Prototype

A self-contained browser prototype for the SIH problem statement: market intelligence + verified buyer matching + transaction enablement for farmers/FPOs.

## Run it

No Node.js, npm, database, or internet connection is required.

1. Extract this folder.
2. Double-click `index.html`.
3. Explore the Farmer, Buyer, and Admin demo flows.

## Included demo features

- Public landing page
- Farmer dashboard
- Localized market price comparison
- Price trend visualization
- Sale-window recommendation (demo logic)
- Crop lot creation
- Buyer matching
- Digital offers and acceptance
- Transaction tracking
- Buyer requirements
- Farmer lot marketplace
- Admin trust/verification dashboard
- Complaints/grievance view
- Responsive layout

## Important

This is a front-end prototype using browser-only demo data. It is designed for an SIH demonstration. Replace the demo data and local state with Supabase/API integration when moving toward a real application.
